Podstawowe polecenia Git
PolecenieZnaczenie
git clonePobranie repozytorium i utworzenie lokalnego katalogu.
git statusSprawdzenie gałęzi oraz plików zmienionych i przygotowanych.
git add Dodanie konkretnego pliku do obszaru staging.
git commit Zapis przygotowanych zmian z czytelnym komunikatem.
git pushPublikacja nowej gałęzi i ustawienie śledzenia.
git pullPobranie zmian bez tworzenia nieoczekiwanego merge commita.
git fetchPobranie informacji o zmianach bez modyfikowania plików roboczych.
git branch Wyświetlenie lokalnych gałęzi i oznaczenie aktywnej.
git switch Utworzenie gałęzi roboczej i przełączenie na nią.
git log Skrócony podgląd pięciu ostatnich commitów.
